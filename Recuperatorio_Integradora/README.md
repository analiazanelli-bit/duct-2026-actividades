# Analizador de Frecuencias - Actividad Integradora

## Descripción
Este programa lee un archivo de texto, cuenta la frecuencia de cada palabra utilizando un diccionario y genera automáticamente un gráfico de barras con las diez palabras más frecuentes.

## Requisitos e instalación
El proyecto requiere Python y la biblioteca `matplotlib`. Se pueden instalar las dependencias necesarias ejecutando:
